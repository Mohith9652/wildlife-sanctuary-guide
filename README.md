# 🐾 Wildlife Sanctuary Guide

**Explore Wildlife. Discover Sanctuaries. Protect Nature.**

Wildlife Sanctuary Guide is a Flutter-based mobile and web application developed to help users explore different wildlife species, discover famous Indian wildlife sanctuaries and understand the importance of wildlife conservation.

## 🌿 Project Overview

The application provides a simple and user-friendly interface where users can explore animal information, search for sanctuaries, save favourite animals and track their wildlife conservation activities.

## ✨ Features

- **Home Dashboard:** Displays project information, animal statistics, sanctuary statistics and featured wildlife.
- **Explore Wildlife:** Browse different animals with their names, categories and habitats.
- **Animal Search:** Search for animals by name.
- **Category Filters:** Filter animals by Mammals, Birds and Reptiles.
- **Favourite Animals:** Add or remove animals from favourites.
- **Animal Details:** View descriptions, habitats and categories.
- **Sanctuary Explorer:** Browse famous Indian wildlife sanctuaries and their locations.
- **Sanctuary Search:** Search sanctuaries by name or location.
- **Conservation Checklist:** Complete wildlife protection activities and track progress.
- **Profile Management:** Edit the displayed username.
- **Theme Settings:** Switch between light mode and dark mode.
- **Notifications:** Enable or disable the notification preference.

## 🚀 How to Run the Project

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Flutter and Dart extensions

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Mohith9652/wildlife-sanctuary-guide.git
```

**2. Navigate to the project directory**

```bash
cd wildlife-sanctuary-guide
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

To run in Google Chrome:

```bash
flutter run -d chrome
```
